# AGENTS.md

Express 5 + Prisma (PostgreSQL) backend. CommonJS, Node >= 18.

## Current state

- The backend uses the layered structure described in the README: controllers, routes, services, validators, middlewares, config, and utils.
- Prisma schema and migrations are the source of truth for the PostgreSQL database.

## Commands

- `npm run dev` - hot-reload dev server (nodemon `src/server.js`)
- `npm start` - production
- `npm test` - not configured; it is a stub that exits 1
- No linter, formatter, or typecheck is configured.

## Prisma

- Requires `DATABASE_URL` in `.env` (copy from `.env.example`). Never commit `.env` or secrets.
- New models require `npx prisma migrate dev`; run `npx prisma generate` after schema-only changes.
- PostgreSQL is accessed through `@prisma/client`.

## Conventions

- Controllers are thin and delegate business logic to services.
- Validation uses Zod schemas in `src/validators` where request validation is needed.
- Errors are handled centrally by `src/middlewares/errorHandler.js` and return `{ success: false, message }`.
- Successful responses return `{ status: "success", data }`.
- Authenticated resources must use `verifyToken` and scope database queries to `req.user.id`.
- Notifications are generated by domain services for likes, comments, and follows; users cannot notify themselves.
